# Iris_K-NN-PCA
---
## 📌 개요  
Iris 데이터를 이용하여 K-NN 분류 알고리즘을 적용하고,  
PCA(주성분 분석)를 거친 데이터로도 모델을 제작하여  
정확도에 어떤 영향을 미치는지 테스트하였습니다.

---

## 🛠 기술 스택  
- Python  
- scikit-learn  
- matplotlib  
- numpy  

### 📦 requirements.txt  
```txt
# Python 3.10.16
geopandas==1.0.1
matplotlib==3.10.1
numpy==2.2.3
pandas==2.2.3
scikit-learn==1.6.1
```

---

## 📚 주요 내용  

- `StandardScaler`를 통해 각 특성(feature)의 평균을 0, 분산을 1로 정규화합니다.  
- `PCA (Principal Component Analysis)`를 사용해 고차원의 데이터를 저차원으로 축소합니다.  
  - 이는 계산 효율성을 높이고 데이터의 본질적인 구조를 파악하는 데 도움을 줍니다.  
- `K-NN (K-Nearest Neighbors)` 알고리즘으로 분류 모델을 구축하고 정확도를 비교합니다.  
- `matplotlib`를 활용하여 데이터와 정확도 비교를 시각화합니다.

## ✅ 결과  

- 주성분 분석(PCA)을 통해 일부 정보가 손실되지만,  
  차원 축소로 인해 모델 성능이 향상되는 경우가 일반적입니다.  

- 그러나 **Iris 데이터셋**은  
  - 특성 수가 적고 (4개)  
  - 표본 수도 많지 않으며  
  - 꽃잎과 꽃받침 길이/넓이만으로도 충분히 분류가 가능합니다.  

- 따라서 **PCA 적용 후 정확도는 오히려 약간 감소**하였습니다.  

### 🔎 결론  
고차원의 데이터에서 특성 간 상관관계가 복잡할 경우,  
**PCA와 같은 차원 축소 기법은 모델 성능 향상에 효과적**일 수 있습니다.  
그러나 단순하고 잘 구분되는 데이터에서는 오히려 성능이 하락할 수 있습니다.
