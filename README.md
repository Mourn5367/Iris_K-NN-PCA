# Iris_K-NN-PCA

개요 

Iris 데이터를 이용하여 K-NN 분류 알고리즘을 사용하고, 
PCA 주성분 분석을 한 데이터로 모델을 제작한다면 모델의 정확도가 높아지는지 테스트하였습니다.

기술 스택

requirements.txt 작성한거 보여주기

주요 내용

sklearn의 StandardScaler를 통해 각 특성의 평균을 0, 분산을 1로 변환합니다.

주성분 분석 PCA(Principal Component Analysis)를 통해 데이터를 고차원에서 저차원으로 축소하여 계산의 효율성을 높이고
데이터의 본질적인 구조를 파악합니다.

matplotlib 라이브러리를 활용하여 원본데이터, PCA 데이터, 모델의 정확도를 시각화 합니다.

결과

일반적으로는 주성분 분석을 통해 일어난 데이터 손실보다 주성분 분석을 통해 얻은 차원 축소의 이점이 더 클 경우 모델의 성능을 향상할 수 있지만, 붓꽃 데이터의 경우 특징 수와 데이터 표본 수가 적고, 이미 꽃잎의 특징을 통해서 분류할 수 있기 때문에 주성분 분석 후 차원이 축소된 데이터는 원본 데이터보다 정확도가 다소 떨어진 것으로 해석됩니다.
 
따라서 고차원의 데이터를 시각화하였을 때 특성들이 복잡하게 얽혀 있어 분류하기 힘든 경우에는 주성분 분석을 통해 모델을 제작하는 것이 효과적이라고 생각합니다.
